# Focused training layout

The Training dashboard uses the same course shortcut card as the main Dashboard, with the recommended lesson named above its start or continue link. The move routine and the first lesson's recall checklist include the question of what is wrong with the opponent's move; course progress and its content version remain unchanged.

When a lesson, puzzle, or game review actually displays a board, the shell hides its sidebar and expands the workspace. Each board view keeps its own return link. Lesson text and exercise controls sit beside the board on wide screens and stack on narrow screens. Puzzle and review board columns can grow with the window. Workspace top padding is reduced throughout the application.
