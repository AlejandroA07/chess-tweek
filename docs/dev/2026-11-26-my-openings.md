# Puzzle My Openings

The Openings page expands each family on request, with links to practice the family and its variations. My Openings starts with London System as a favorite and Caro-Kann Defense, if those families exist in the imported catalog. Users can add and remove available families, favorite them or their variations, and reorder items within each favorite or non-favorite group. Favorite items are displayed first; variations retain their own order per family. Family and variation practice links use the existing puzzle selection behavior.

Preferences are stored in browser local storage under the connected Lichess account ID, not in SQLite: they persist in that browser on this Mac but do not transfer to another browser and are removed if browser site data is cleared. A storage failure is reported and does not pretend to save. Saved data is bounded and validated before use; category names and links are derived only from the current validated catalog. This does not add an endpoint or change puzzle progress.

Security checklist: authentication and authorization for the existing category endpoint remain unchanged; account-scoped browser preference keys are not an authorization boundary and contain no credentials. Input bounds, catalog filtering, safe error handling, output encoding, and no dynamic SQL pass. Tests cover malformed storage and failed writes. Tokens, file uploads, server-side requests, webhooks, redirects, server commands, rate-limited endpoints, dependencies, and CI changes are not applicable. Preferences are not confidential from other users of the same browser profile.
